Place the price file here as `prices.csv`: one `Date` column followed by one column of daily
adjusted closing prices per instrument. The paper uses 2005-08-25 to 2025-08-25 for 88 large US
stocks, the nine Select Sector SPDR ETFs (XLK, XLF, XLV, XLE, XLI, XLY, XLP, XLU, XLB) and the
index columns ^GSPC, ^RUT, ^NDX, ^VIX (indices, ^VIX and GOOG are dropped by the scripts).
The price data itself is not redistributed in this repository.
